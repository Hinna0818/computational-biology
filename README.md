# Computational Biology – Course Experiments (2025)

This repository contains experiment codes and analysis workflows developed for the **Computational Systems Biology** course (Nov–Dec 2025).  
The experiments focus on applying computational and machine learning methods to biological network analysis and predictive modeling.

---

## 📂 Repository Overview

This repository covers a range of core topics in computational and systems biology, including:

- **Protein–Protein Interaction (PPI) Network Construction**
- **Network Analysis and Graph Algorithms**
- **Machine Learning Models for Biological Prediction**
- **Feature Selection and Model Evaluation**
- **Visualization of Biological Networks and Model Outputs**

The codebase emphasizes **reproducible analysis**, **clear methodology**, and **biologically interpretable results**.

---

## 🔬 Experiment Topics

### 1. Protein–Protein Interaction (PPI) Network Analysis
- Construction of PPI networks from curated interaction datasets  
- Network representation using `igraph`
- Analysis of network properties (degree, centrality, connectivity)
- Identification of key proteins using topological measures

### 2. Network Algorithms
- Graph traversal and subnetwork extraction
- Centrality-based node prioritization
- Exploration of network structure and robustness

### 3. Machine Learning for Biological Prediction
- Binary classification models for biological outcomes
- Algorithms used:
  - Elastic Net–regularized Logistic Regression
  - Random Forest
  - XGBoost
- Model comparison based on ROC–AUC and other performance metrics

### 4. Feature Selection and Model Interpretation
- Recursive Feature Elimination (RFE)
- Regularization-based feature selection
- Interpretation of selected biological features

### 5. Visualization
- Network visualization for PPI graphs
- PCA and dimensionality reduction for sample exploration
- ROC curves and performance comparison plots
